# Hops

Four hops. The idea hop is 20% of the window, build is 50%, ship is 20%, roast is 10%.

| Hop | Closes through | Allowed work |
| --- | --- | --- |
| idea | a lock (four gates) | questions only |
| build | a working core flow | the one-liner, nothing else |
| ship | a public URL | deploy, incognito check, one-sentence summary |
| roast | the honest read | compare promise to artifact, one next move |

Overtime rule: no new work. Publish whatever exists, then roast. An imperfect URL beats a perfect plan.

Event addendum: the idea must fit the theme in `.habitat/event.md`. The ship must meet every submission requirement before the deadline. A great build that misses a requirement scores zero.
