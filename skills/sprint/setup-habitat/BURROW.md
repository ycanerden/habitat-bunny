# The burrow

Everything lives in `.habitat/` at the repo root.

| File | Who writes it | What it holds |
| --- | --- | --- |
| `sprint.md` | setup, start-sprint, today | Current sprint: hops, deadlines, locked idea |
| `backlog.md` | check-scope | Parked feature ideas |
| `ships.md` | ship | Everything that made it to a URL, with a share template |
| `event.md` | start-sprint (event mode) | Event brief, theme, rules, judging |
| `state.json` | MCP only | Machine state. Skills may read it. Skills do not invent a parallel schema. |

Delete the folder and the bunny forgets everything.

If the MCP is later installed in the same repo, it reads this same folder. Do not fork the format.
