# Check scope

MUST run before you write a single line of a feature that was not in the locked one-liner.

## If nothing is locked

There is no scope to protect. Call the Skill tool with "grilling" instead. If this feature *is* the idea, grill that one.

## If the idea is locked

1. Name the locked one-liner back to them, once.
2. Park the new idea. Do not debate whether it is "small."
3. Write it to `.habitat/backlog.md` with the time.
4. If the MCP is connected, also call `check_scope` with `feature`.
5. Return to the locked sentence.

Default answer is: parked, not built. The backlog remembers so the builder does not have to.

Tonight is exactly one sentence. Every minute on a side quest is a minute the ship hop does not get.
