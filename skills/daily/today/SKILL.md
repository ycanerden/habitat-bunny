# Today

The builder is already in the middle of something. They do not need an evening container. They need one hop.

Do not ask them to say a ritual phrase. If they ramble ("I am building something and I am not sure what"), that ramble is the input.

## Lock one sentence

If there is no lock in `.habitat/sprint.md` for today:

1. Call the Skill tool with "grilling" on whatever they just said.
2. The out-of-scope list still needs two items. Today is smaller than a sprint, not sloppier.
3. Write the lock. Current hop: build. Clock: now plus the hours they named, or 4.

Vague intents fail: "work on the app", "fix bugs", "make it better", "keep going". Re-grill.

If a lock for today already exists, do not re-litigate it. New directions go through check-scope.

## Take it to a URL

Build only that sentence. Mid-build ideas: call the Skill tool with "check-scope". Drift: call the Skill tool with "pace".

When the core flow works, call the Skill tool with "picasso", then "ship", then "roast". Do not show a stranger the extra features or the fluffy sentence.

If the MCP is connected, prefer its tools for the same gates. There may not be a `today` tool on older servers; `start_sprint` in solo mode with a short `hours` window is an honest fallback.
