# Skills are not the gate

A skill can tell the agent to refuse localhost. An agent can ignore a skill.

Do not replace MCP tool rejects with skill prose and call it shipped. If a check matters (vague ICP, skipped hop, localhost), it lives in `src/` and the tool returns no.

Skills may *also* write the same rule so a builder without the MCP still gets the ritual. That is a fallback, not the product.
