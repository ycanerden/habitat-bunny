## What it does

`ask-bunny` is the map. You type it when you cannot remember which hop to run. It does not start a sprint and it does not grill you. It points.

The defining constraint: it is a router, not a hop. If you already know you want an evening, skip it and type `/start-sprint`.

## When to reach for it

You invoke this by typing `/ask-bunny`, and the agent won't reach for it on its own.

Reach for it when you are stuck at the door: sprint or today, event or solo, grill or just ship. If you already have a locked one-liner and a clock, you want [pace](../daily/pace.md), not this.

## The map, not the evening

Habitat has two front doors:

| You are… | Type |
| --- | --- |
| Starting an evening or an event | `/start-sprint` |
| Already building, and lost | `/today` |
| Setting up a repo for the first time | `/setup-habitat` |

Everything else is a gate the front doors pull in.

## Common questions

**Do I need this every time?**
No. It exists because no one remembers nine names. After one sprint you will reach for `/start-sprint` or `/today` directly.

**Will the agent suggest it?**
No. That is the point of a user-invoked router. If it auto-fired, it would interrupt the hop you are already on.

## It's working if

- You leave with one next command, not a tour of every skill.
- You did not start building during the map.

## Where it fits

Run-once-when-lost standalone. The rest of the set hangs off it. Neighbours: [start-sprint](./start-sprint.md) (the evening) and [today](../daily/today.md) (the on-ramp).
