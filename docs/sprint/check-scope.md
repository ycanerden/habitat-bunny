## What it does

`check-scope` parks a mid-sprint feature idea in `.habitat/backlog.md`. The idea is not forgotten. It is not tonight.

The defining constraint: the default answer is no. Small does not mean now.

## When to reach for it

Type `/check-scope`, or the agent reaches for it automatically when a "quick add" appears after the lock, or when you say "also we should".

Reach for this during build. If nothing is locked yet, you want [grilling](./grilling.md).

## Parked, not rejected

The backlog exists so you can let go. A parked line is a gift to tomorrow's sprint, not a scolding.

## Common questions

**What if this feature *is* the product?**
Then you locked the wrong one-liner. That is a new sprint, not a drive-by add. Finish the URL you promised first.

**Does the MCP have to be installed?**
No. The skill writes the same markdown file the MCP would.

## It's working if

- `.habitat/backlog.md` grew and the working tree did not.
- You can still say the one-liner out loud without listing the parked idea.
