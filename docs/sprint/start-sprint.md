## What it does

`start-sprint` is the Habitat night: a clock, a locked one-liner, four hops. Your agent builds. This skill paces.

The defining constraint: it will not let you skip a hop. No build before the lock. No roast before a public URL.

## When to reach for it

You invoke this by typing `/start-sprint`, and the agent won't reach for it on its own.

Reach for it when you have an evening (or a hackathon deadline) and you want a stranger to click something before you stop. If you are already mid-build and only need one sentence for today, use [today](../daily/today.md).

## Solo, team, event

The first question is how you are sprinting. Event mode changes the clock (the real deadline) and the roast (the actual judging criteria). It will not start the clock without the brief.

## Prerequisites

A burrow. If `.habitat/` is missing, run `/setup-habitat` first.

## Common questions

**Can I add a feature I thought of during build?**
Yes, to the backlog. [check-scope](./check-scope.md) parks it. It is not tonight.

**What if I only have localhost?**
Then you have not shipped. [ship](./ship.md) will say so.

**Do I need the MCP?**
No. The skill runs the ritual in prose and writes the same files. The MCP is the gate that will also refuse from a tool.

## It's working if

- You can point at a one-liner that a friend could repeat.
- Something is parked in `.habitat/backlog.md`.
- A stranger can open a URL before the roast starts.

## Where it fits

The main chain: setup → start-sprint → grilling → build (check-scope, pace) → ship → roast. The router is [ask-bunny](./ask-bunny.md).
