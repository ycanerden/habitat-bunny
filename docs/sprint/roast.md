## What it does

`roast` is the last hop. It compares the locked promise to the live artifact, names the weakest dimension, and gives you one next validation move.

The defining constraint: it will not run before a public URL exists. There is nothing honest to say about a plan.

## When to reach for it

Type `/roast`, or the agent reaches for it automatically after a ship, when you ask for a roast or retro, or when you try to call the night done from build.

Reach for this when the URL is live. If it is not, you want [ship](./ship.md).

## Prerequisites

A lock and a ship.

## Promise versus artifact

The roast is not a vibe check and not a roast-comedy set. Idea, product, potential: rank them with evidence. Then one change you can make in under 30 minutes tomorrow, and exactly one way to put it in front of the ICP.

## Common questions

**Will it be mean?**
Clear, not cruel. If it stings, it is usually because the one-liner promised more than the page does.

**Can I skip it? I need to sleep.**
You can sleep. The learning lives here. Five minutes.

## It's working if

- You can name the gap between the one-liner and the URL in one sentence.
- You have exactly one next move, not a roadmap.
