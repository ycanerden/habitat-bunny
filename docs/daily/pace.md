## What it does

`pace` reads the clock and says which hop you are on. It is the nudge when the conversation drifts or you go quiet.

The defining constraint: it does not add work to fill remaining time. Overtime means publish whatever exists.

## When to reach for it

Type `/pace`, or the agent reaches for it automatically at checkpoints, when you go quiet, when the chat drifts, or when a hop deadline has passed.

Reach for this during a live sprint or today-lock. If there is no burrow and no clock, you want [today](./today.md) or [start-sprint](../sprint/start-sprint.md).

## The clock is the boss

On pace: stay on the hop. Behind: close it with whatever is on the table. The table of nudges lives in the skill; you should feel it as a sentence, not a dashboard.

## Common questions

**Can I ignore it and keep polishing?**
You can. The skill will say the same thing the next time it fires. The MCP `sprint_status` tool will too.

**Does it need the MCP?**
No. It can read `.habitat/sprint.md`. The tool is nicer because the remaining time is computed for you.

## It's working if

- Someone said the remaining time out loud.
- You moved hop, or you had a reason not to.
